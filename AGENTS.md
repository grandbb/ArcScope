# Project identity

The product name is **AScope**. Use `AScope` in visible copy and `ascope` for package names, filenames, downloads, and browser storage keys. Keep new assets and documentation consistent with this name.

The deployed gARC contract on Arc Mainnet is immutable. Its original event message and executable runtime are preserved only for verifying and reading that existing deployment. New contract source and deployments use `gARC | AScope`.
